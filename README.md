# НОВАТА ИНВЕСТ — сайт

Лендинг ИАС «Новата Инвест». Главная задача сайта — получать заявки.

Дизайн — направление «Институциональный»: тёплая бумага вместо белого, крупная
антиква в заголовках, волосяные линейки вместо карточек, нулевые скругления,
один чернильно-синий акцент.

**Тексты не менялись**: все заголовки, абзацы, подписи, юридические документы и
подписи кнопок совпадают с исходной версией.

---

## Структура

```
index.html                  главная страница
policy.html                 Политика конфиденциальности
agreement.html              Согласие на обработку персональных данных

assets/
  novata.css                ДИЗАЙН-СИСТЕМА: токены + примитивы + компоненты
  site.css                  композиция страниц поверх дизайн-системы
  site.js                   поведение: меню, форма, модальные окна, cookies
  logo.png  eldar.png  safe.png  favicon.ico

standalone/                 автономные копии (генерируются, см. ниже)
build-standalone.py         сборка автономных копий
DESIGN-SYSTEM.md            описание дизайн-системы
```

Две версии одного и того же сайта:

1. **`index.html` + папка `assets/`** — обычная версия. Работает, если
   `index.html` и папка `assets` лежат рядом.
2. **`standalone/index.html`** — всё (стили, скрипты, картинки) вшито внутрь
   одного файла. Работает сам по себе, из любой папки. Его удобно вставлять
   в Tilda или пересылать одним вложением.

Пересобрать автономные копии после любой правки:

```bash
python3 build-standalone.py
```

## Заявки

Форма находится в блоке `#form` на главной. Что уже работает:

- проверка полей на стороне браузера с понятными сообщениями об ошибке;
- маска телефона `+7 (000) 000-00-00`;
- скрытое поле-ловушка (honeypot) против спам-ботов;
- экран «Спасибо! Заявка получена.» вместо перезагрузки страницы;
- дублирующие кнопки «Получить консультацию»: в шапке, в первом экране,
  в блоке решений, в подвале и плавающая кнопка внизу экрана на телефоне.

### Куда уходят заявки

Сейчас приёмник заявок **не подключён**: форма работает в демо-режиме и просто
показывает подтверждение. Чтобы заявки начали приходить, откройте
`assets/site.js` и укажите адрес приёмника в первой строке настроек:

```js
var LEAD_ENDPOINT = 'https://formspree.io/f/ваш-id';
```

Подойдёт Formspree, вебхук Tilda, Make/Integromat или свой обработчик. Данные
уходят методом `POST` в формате JSON:

```json
{ "name": "...", "email": "...", "phone": "...",
  "agree_data": true, "agree_policy": true, "page": "..." }
```

Если запрос не прошёл, посетителю открывается почтовый клиент с письмом на
`info@novata-invest.ru` — заявка не теряется.

После правки `assets/site.js` не забудьте пересобрать `standalone/`.

## Юридические ссылки в форме

Требование: ссылки на согласие и политику в форме должны работать. Сделано так,
что они работают в любом варианте размещения:

- ссылки ведут на `agreement.html` и `policy.html` — работают без JavaScript
  и открываются в новой вкладке;
- при включённом JavaScript документ открывается **модальным окном прямо
  поверх формы** — посетитель читает документ и не теряет заполненные поля;
- тексты документов лежат в `index.html` в тегах `<template id="legal-…">`,
  поэтому модальное окно работает и в автономной версии, где отдельных файлов
  рядом может не быть;
- в подвале те же ссылки продублированы.

> **Важно:** текст документа хранится в двух местах — на отдельной странице
> (`policy.html` / `agreement.html`) и в `<template>` внутри `index.html`.
> При изменении юридического текста правьте оба места.

### Публикация в Tilda

Замените адреса юридических страниц на адреса ваших страниц в Tilda —
поиском-заменой по файлу:

- `agreement.html` → `/agreement`
- `policy.html` → `/policy`

## Проверено

- Разрешения 1440 / 1280 / 960 / 768 / 390 px — горизонтальной прокрутки нет.
- Работают: меню и плавная прокрутка, бургер-меню, кнопки телефона и почты,
  проверка формы, модальные окна с документами, cookie-баннер с запоминанием,
  плавающая кнопка заявки на телефоне.
- Анимации отключаются при системной настройке «уменьшить движение».
