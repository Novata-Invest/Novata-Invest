# Дизайн-система «Новата Инвест» v2

Один файл — `assets/novata.css`. Он не знает ничего о конкретных страницах:
только токены, типографика, кнопки, поверхности и поля формы. Вся раскладка
страниц живёт отдельно, в `assets/site.css`.

## Что было извлечено из старой вёрстки

Старый сайт держал оформление в двух несвязанных блоках `<style>`: главная
знала про `--navy`, `--card`, `--lightblue`, юридические страницы — про свои
`--blue`, `--ice`, `--line`. Размеры, отступы и радиусы задавались числами по
месту: `font-size:55px`, `padding:80px 0`, `border-radius:12px`, `gap:36px`.

Что взято из старой версии без изменений:

| Наследие | Значение | Роль в v2 |
| --- | --- | --- |
| Тёмно-синий | `#051A3B` | `--nv-navy-900` — ядро бренда |
| Акцентный синий | `#1E5FE0` | `--nv-blue-600` — основное действие |
| Светло-голубой | `#DCE8F7` | `--nv-blue-100` — мягкая заливка |
| Шрифт | Manrope 400–800 | `--font` |
| Ширина макета | 1200 px | `--container` |

Что добавлено, чтобы система стала полной: нейтральная шкала, сигнальный
зелёный `#12B886` (подтверждение, защита капитала), шкалы размеров, отступов,
радиусов, теней и движения, а также семантический слой `--bg/--fg/--border/
--accent`, который переключается на тёмных поверхностях классом `.on-dark`.

## Слои

```
1. Токены        цвет, шрифт, размер, отступ, радиус, тень, движение
2. База          reset, body, фокус, выделение
3. Раскладка     .container, .section, .grid, .stack, .cluster
4. Типографика   .display .h1 .h2 .h3 .lead .small .fine .eyebrow
5. Кнопки        .btn + 7 вариантов, .icon-btn
6. Поверхности   .card .panel .badge .icon-tile .divider
7. Поля формы    .field .input .check .link-legal
8. Движение      [data-reveal], prefers-reduced-motion
9. Утилиты       .visually-hidden .text-center .grid--2/3/4
```

## Цвет

Бренд: `--nv-navy-950 / -900 / -800 / -700`, `--nv-blue-700 / -600 / -500 /
-200 / -100 / -50`, `--nv-mint-500 / -100`.
Нейтральные: `--nv-ink`, `--nv-ink-2`, `--nv-ink-3`, `--nv-line`,
`--nv-line-soft`, `--nv-surface`, `--nv-surface-2`, `--nv-surface-3`.

Компоненты не обращаются к брендовым переменным напрямую — они читают
семантический слой:

```css
--bg --bg-muted --fg --fg-muted --fg-subtle --border --border-soft
--accent --accent-fg --danger
```

Поэтому тёмный первый экран и тёмный блок заявки не требуют отдельных правил:
класс `.on-dark` переопределяет семантические токены, и те же `.btn--outline`,
`.eyebrow`, `.badge` работают на тёмном фоне.

## Типографика

Плавная шкала на `clamp()`, один шрифт, вес 400–800:

```
--t-display  2.10 → 3.50 rem   первый экран
--t-h1       2.00 → 3.10 rem   заголовок внутренней страницы
--t-h2       1.65 → 2.45 rem   заголовок секции
--t-h3       1.12 → 1.40 rem   карточка, шаг
--t-lead     1.02 → 1.22 rem   подзаголовок
--t-body     1.00 rem          текст
--t-sm       0.94 rem          вторичный текст
--t-xs       0.81 rem          подписи, дисклеймеры
```

Трекинг `-0.025em` на крупных кеглях, `text-wrap: balance` на заголовках.

## Размеры

- Отступы: шаг 4 px, `--s-1 … --s-32`.
- Радиусы: `--r-xs 8` → `--r-2xl 36`, `--r-full` для кнопок.
- Тени: `--sh-1 … --sh-4` (мягкие, с отрицательным spread) и `--sh-focus`.
- Движение: `--dur-1 .16s`, `--dur-2 .28s`, `--dur-3 .55s`, `--ease`,
  `--ease-out`.

## Кнопки

Один класс `.btn` + вариант. Цвет задаётся тремя локальными переменными
(`--btn-bg`, `--btn-fg`, `--btn-bd`), поэтому новый вариант — это три строки.

| Вариант | Где применяется |
| --- | --- |
| `.btn--primary` | главное действие: «Получить консультацию», «Отправить» |
| `.btn--navy` | второе по важности действие на светлом фоне |
| `.btn--outline` | вторичное действие; сам подстраивается под `.on-dark` |
| `.btn--soft` | мягкий акцент на светлом |
| `.btn--light` | действие на тёмном фоне |
| `.btn--sm / --lg / --block` | размер и растяжение по ширине |

Минимальная высота 54 px (44 px у `--sm`) — достаточно для касания пальцем.

## Доступность

- Видимый фокус: `:focus-visible` с внешним контуром, у кнопок и полей —
  кольцо `--sh-focus`.
- Контраст текста на всех фонах — не ниже AA.
- У полей формы есть скрытые `<label>`; ошибки помечаются `aria-invalid` и
  текстом рядом с полем.
- Модальные окна: `role="dialog"`, `aria-modal`, закрытие по Esc и по клику
  мимо окна, возврат фокуса на элемент, который окно открыл.
- `prefers-reduced-motion: reduce` отключает появление блоков и плавную
  прокрутку.

## Как расширять

1. Новый оттенок — сначала в брендовую шкалу, потом при необходимости в
   семантический слой. Не пишите hex внутри компонента.
2. Новый размер — берите из шкалы `--s-*`; если шага не хватает, добавьте его
   в шкалу, а не в компонент.
3. Новый компонент — сначала посмотрите, не собирается ли он из `.card`,
   `.icon-tile`, `.badge` и `.btn`.
4. Тёмный фон — не пишите отдельные правила, навесьте `.on-dark` на контейнер.
